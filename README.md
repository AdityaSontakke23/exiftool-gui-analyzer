# ExifTool GUI Analyzer

A lightweight, cross-platform graphical user interface (GUI) for Phil Harvey's ExifTool. This project was developed as part of a Network Information and Security internal assessment to demonstrate metadata extraction, forensic analysis, and security vulnerability concepts.

## Features
* **Simple Interface:** Built with Python and `tkinter` for a zero-dependency graphical experience.
* **Instant Extraction:** Select any image file to instantly parse and view its embedded EXIF, XMP, and IPTC metadata.

## Prerequisites
To run this application, you must have ExifTool installed on your system.
* **macOS:** `brew install exiftool`
* **Linux:** `sudo apt install libimage-exiftool-perl`
* **Windows:** Download the executable from [exiftool.org](https://exiftool.org/)
